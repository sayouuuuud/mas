# تسليم المرحلة الأولى: الواجهات فقط

> تم استكمال وظائف إضافية في المرحلة الثانية. راجع [مراجعة اكتمال الواجهات](./FRONTEND-COMPLETENESS.ar.md) لوصف النسخة الحالية؛ البنود أدناه توثق التسليم الأول.

التاريخ: 16 نوفمبر 2026. المرجع الوظيفي: [PRD](./PRD.ar.md).

## حدود التنفيذ

هذه المرحلة واجهات تفاعلية ببيانات صناعية محلية. لا تتضمن Supabase أو قاعدة بيانات أو API أو Server Actions أو مصادقة أو رفع ملفات إلى خدمة خارجية. استخدام Next.js لعرض الصفحات والمسارات لا يضيف خدمة حفظ بيانات.

- بيانات الكتالوج والنماذج: `lib/demo-data.ts`.
- حالة المنتجات والطلبات المشتركة أثناء التنقل: `components/demo/demo-provider.tsx`.
- تعديلات الإدارة مؤقتة في الذاكرة وتعود للأصل عند تحديث الصفحة؛ نماذج القواميس والمحتوى تعود للأصل عند مغادرة الصفحة.
- السلة وحدها تحفظ معرفات المتغيرات وكمياتها في `sessionStorage`؛ لا تحفظ بيانات التواصل أو كلمات المرور.
- لا توجد أرقام طلبات حقيقية أو إشعارات إرسال أو عرض سعر صادر. الأرقام التي تبدأ بـDEMO أمثلة ثابتة.
- دخول الإدارة واستعادة كلمة المرور نموذج واجهة فقط. رابط المعاينة مستقل ومتاح دون حساب، ولا يمثل تجاوزًا لمصادقة حقيقية.
- ملفات الوسائط تُعرض عبر object URLs داخل المتصفح مع التحقق الأولي من النوع والحجم؛ لا تُرفع ولا تُفحص أمنيًا ولا تُنشر. إلغاء object URLs يتم عند الإزالة ومغادرة الصفحة.
- عرض السعر يقدم حسابًا توضيحيًا وطباعة المتصفح، ولا يُصدر ملف PDF رسميًا أو رقمًا أو إرسالًا تجاريًا.
- المنتجات تحمل صور المجموعات الحالية ومواصفات تجريبية، وليست منتجات معتمدة أو بيانات مورد أو ادعاء توافق فني.
- منع فهرسة الصفحات الجديدة والإدارة عبر metadata حتى استبدال البيانات التجريبية.

## صفحات الموقع العام

| المسار | الواجهة |
|---|---|
| `/` | الرئيسية الحالية مع ربط التنقل بالصفحات الجديدة |
| `/products` | البحث والفرز والفلاتر وترقيم الصفحات والنتيجة الفارغة |
| `/products/engine-oil` | مثال تفاصيل منتج: صورة مكبرة، عبوات، كمية، سلة، تبويبات ومواصفات وملفات غير متاحة ومنتجات مرتبطة |
| `/categories` | مجموعات المنتجات |
| `/categories/oils`, `/categories/grease`, `/categories/bearings` | كتالوج مقيد بالمجموعة |
| `/brands` و`/brands/skf` | العلامات ومنتجات علامة محددة |
| `/sectors` و`/sectors/factories` | القطاعات ومنتجات مرتبطة بقطاع |
| `/about` | تعريف الشركة وروابط الكتالوج |
| `/contact` | التواصل المباشر ونموذج معاينة الاستفسار |
| `/request-quote` | سلة عرض السعر والبنود الحرة وبيانات التواصل والتحقق ومعاينة النموذج |
| `/request-quote/success` | حالة محايدة توضح عدم وجود إرسال فعلي، وليست تأكيد استلام وهميًا |
| `/privacy`, `/terms` | مسودات سياسة وشروط تحتاج اعتمادًا قبل جمع البيانات |
| مسار غير معروف | صفحة 404 محلية بالعربية والإنجليزية |

اللغة تستخدم مفتاح العربية/الإنجليزية وcookie الحالي. مسارات `/ar` و`/en` وفهرستها النهائية الواردة في الـPRD لم تُفعّل في هذه المرحلة؛ المسارات أعلاه مستقلة عن اللغة. روابط معاينة المنتجات تعتمد معرفات ثابتة حتى تعمل التعديلات المحلية أثناء التنقل؛ ربط slugs وتحويلاتها النهائي يأتي مع مصدر البيانات لاحقًا.

## التصميم وإتاحة الاستخدام

- الحفاظ على ألوان M.A.S الأساسية: البترولي `#267f92` والكحلي `#172f3a` والذهبي `#bd9f58`.
- إعادة استخدام صور وهوية الموقع، مع واجهة إدارة منفصلة مناسبة للجداول والنماذج.
- دعم العربية RTL والإنجليزية LTR، وقوائم موبايل وجداول قابلة للتمرير أفقيًا باللمس ولوحة المفاتيح.
- ربط labels بعناصر الإدخال، حالات فارغة ورسائل تحقق واضحة، رابط تخطي المحتوى، وتكبير صورة باستخدام native dialog لدعم التركيز وEscape.
- تضمين Tajawal وInter محليًا مع تراخيصهما في `public/fonts` لإلغاء اعتماد البناء على Google Fonts.
- تفعيل فحص TypeScript أثناء `next build` بدل تجاهل أخطاء الأنواع.

## التحقق المنفذ

- `pnpm build`: بناء إنتاج ناجح مع فحص TypeScript.
- `pnpm exec tsc --noEmit --incremental false`: ناجح.
- `git diff --check`: ناجح.
- Playwright مع Chromium على نسخة الإنتاج: 31 مسارًا، بحث وفلاتر ونتيجة فارغة، اختيار العبوة والكمية، الإضافة للسلة واستمرارها بعد تحديث الصفحة، معاينة النموذج، واجهة الدخول، تعديل المنتج المؤقت، الإنجليزية/LTR، وفحص عدم تجاوز عرض الشاشة لصفحات أساسية على 390px، و404، دون أخطاء JavaScript.
- اختبارات تفاعل إضافية: إغلاق نافذة الصورة بـEscape، إضافة ملاحظة متابعة، تحرير تصنيف محليًا، معاينة عدة ملفات دون فقد الصور السابقة، حساب مسودة العرض، وفلاتر وتنقل الموبايل على 360px؛ دون طلبات كتابة للتطبيق أو أخطاء متصفح.

## المرحلة التالية

مراجعة الصفحات والمحتوى الحقيقي أولًا. بعد اعتماد الواجهات وبطلب منفصل: تنفيذ الجداول وRLS وAuth وStorage وAPI، واستبدال بيانات العرض، وربط الحفظ والإرسال والإصدار والصلاحيات الفعلية. جميع القواعد الأمنية والتجارية في الـPRD تظل متطلبات تنفيذ لاحقة، ولا تعني الأزرار التجريبية أنها مطبقة حاليًا.
