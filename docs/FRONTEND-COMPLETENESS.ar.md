# مراجعة اكتمال الواجهات — المرحلة الثانية

16 نوفمبر 2026. المرجع: [PRD](./PRD.ar.md). هذه الوثيقة تحل محل وصف حدود المرحلة الأولى في [التسليم السابق](./FRONTEND-PHASE-1.ar.md).

## النطاق

استكمال صفحات وتفاعلات الفرونت للكتالوج وطلبات الأسعار والإدارة، دون API أو قاعدة بيانات أو Supabase أو Server Actions. كل بيانات العمل والتعديلات والملفات المختارة تبقى داخل ذاكرة جلسة المعاينة. السلة فقط تحفظ المعرفات والكميات في sessionStorage، ولا تحفظ بيانات اتصال أو كلمات مرور فيه.

لا تعني تغطية واجهات المتطلبات أن الموقع أصبح نظام إنتاج مكتملًا: المصادقة والحفظ الموثوق والصلاحيات والإرسال والفحص الأمني والتكاملات تحتاج الباك إند واختبارات الربط. المحتوى والمنتجات والقيم الفنية الحالية عينات للمراجعة.

## المظهر والتنقل

- خلفية صناعية مصورة وتظليل واضح لكل عناوين الصفحات التي تستخدم PageIntro، مع تباين مناسب للعربية والإنجليزية.
- خلفيات بتدرج لوني وتفاصيل هندسية للكروت التعريفية والقطاعات والعلامات، مع حالات hover وfocus.
- الداشبورد رابط مستقل. مجموعات الإدارة القابلة للطي بالترتيب: المبيعات والعملاء، الكتالوج والمنتجات، إدارة الموقع، التقارير والنشاط، الفريق والصلاحيات.
- المجموعة الخاصة بالصفحة الحالية تُفتح تلقائيًا، والرابط النشط مميز. القائمة تدعم لوحة المفاتيح؛ قائمة الموبايل تدعم Escape وإدارة التركيز ومنع الوصول لعناصرها عند إغلاقها.
- مسارات عربية وإنجليزية مثل `/ar/products` و`/en/products`، مع الحفاظ على فلاتر الصفحة عند تبديل اللغة. المسارات السابقة مثل `/products` ما زالت تعمل.
- صفحات البيانات التجريبية والإدارة غير مفهرسة. إعداد SEO النهائي والفهرسة ومحتوى HTML الإنتاجي يُراجعان عند توصيل مصدر المحتوى الحقيقي.

## التحقق

بناء الإنتاج يشمل فحص TypeScript، وفحص التغييرات بـ`git diff --check`. تُختبر مسارات عامة وإدارية، ثم رحلات مترابطة عبر التنقل داخل التطبيق لضمان بقاء بيانات الجلسة؛ التنقل الكامل أو تحديث المتصفح يعيد بيانات المعاينة.

تشمل الاختبارات كذلك الحساب العشري والتقريب والكميات والخصومات، وCSV ذو النصوص المقتبسة والأسطر المتعددة، وحماية المراجع، والمحتوى والإعدادات المشتركة، وحالات الحساب والملفات، وRTL/LTR والموبايل. نتائج التشغيل النهائية تذكر في رسالة التسليم؛ هذه ليست شهادة بخلو كل حالة ممكنة من العيوب.

نتيجة التحقق على نسخة الإنتاج الحالية: اجتازت 43 مسارًا وثلاث مجموعات تحقق بالمتصفح، تشمل الرحلة المترابطة، والحالات الإضافية، والكتابة السريعة والفلاتر المتعددة. لم تُرصد أخطاء JavaScript أو طلبات كتابة شبكة في الرحلات المختبرة. فُحص العرض على 360 و390 بكسل، وتجاوز العرض في محرر عروض الأسعار تم إصلاحه. أضيفت اختبارات انحدار قابلة لإعادة التشغيل للحسابات والكميات والهواتف وCSV بالأمر: `node --test tests/frontend-model.test.cjs`.

## حدود الربط القادم

- استبدال حالة الذاكرة بمصادر البيانات وواجهات Supabase بعد طلب البدء في الباك إند.
- تطبيق Auth وRLS والتحقق بالخادم والمعاملات وidempotency والنسخ الاحتياطي والتدقيق الدائم.
- رفع الملفات إلى Storage وفحصها وتوقيع روابط الملفات الخاصة؛ اختيار ملف محلي لا يعني اعتمادًا أمنيًا.
- إصدار مستندات PDF رسمية وإشعارات خارجية وأرقام عمل حقيقية وإرسال موثوق.
- اعتماد بيانات المنتجات والمواصفات والصور والنصوص القانونية، ثم مراجعة الفهرسة وSEO الإنتاجي بعد الربط.

لا يُضاف شراء أو دفع أو مخزون كمي؛ تظل حدود المشروع كتالوجًا وطلبات عروض أسعار كما تم الاتفاق.

تحديث مرحلة لاحقة: أضيفت خدمات الباك إند وmigrations واختباراتها بشكل مستقل؛ راجع [حالة الباك إند وحدود الربط الفعلي](./BACKEND.ar.md). يظل سلوك الواجهة الموضح هنا معاينة إلى أن تُستبدل مصادر بياناتها وتُختبر مع المشروع المتصل.
