# حالة ربط الواجهات — 17 نوفمبر 2026

الحالة الفعلية ونتائج الاختبارات وحدود النشر موثقة في [PROJECT_STATUS.md](../PROJECT_STATUS.md). هذه الوثيقة تحل محل تقرير المعاينة القديم؛ لا تعتبر نتائجه السابقة إثباتًا لنجاح النظام المتصل.

الكتالوج والمحتوى والإدارة والمصادقة والطلبات تستخدم `lib/api-client.ts` و`useLiveQuery`. `DemoProvider` اسمه تاريخي: يحتفظ بسلة الزائر والمقارنة وآخر إيصال فقط، ولا ينشئ منتجات أو طلبات عمل في الذاكرة. لا يعاد إنشاء بيانات العمل بعد تحديث المتصفح. حسابات الإدارة تعرض دور Admin وحده، مع Owner داخلي لتوافق RPC.

التصميم والخلفيات والبطاقات ومجموعات القائمة القابلة للطي محفوظة. لا يوجد شراء أو دفع أو حساب عميل عام أو مخزون كمي. التسليم المسجل لعروض الأسعار تواصل يدوي وليس إرسال بريد أو واتساب آليًا.

نجحت فحوص TypeScript والبناء، واختبارات عرض 30 حالة صفحة/حجم، واختبارات متصفح بعقود API معترضة للحفظ والتعارض والملاحظات والعروض. لا تُحسب اختبارات API المعترضة رحلات حفظ إنتاجية. الدخول الحقيقي وMFA والرفع والفحص والإرسال وPDF على الموقع المنشور ما زالت تحتاج إغلاق متطلبات التشغيل المسجلة في ملف الحالة.
