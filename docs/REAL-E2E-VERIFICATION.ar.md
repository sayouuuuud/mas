# نتيجة اختبار الرحلة الفعلية — 17 نوفمبر 2026

## نطاق النتيجة

نجحت الرحلات المطلوبة باستخدام متصفح Chromium وخدمات Auth وPostgreSQL وPostgREST وStorage فعلية، وClamAV لفحص الملفات. نُفذت على نسخة اختبار محلية معزولة من `main` بعد دمج PR #4، عند commit `d362a6d25fc45c54b73cd9e3b6a411804d52e1e7`. لم تُعترض استجابات API ولم تُزوّر جلسات MFA أو حالات الملفات أو نتائج PDF.

هذه نتيجة تكامل محلية، وليست إثباتًا أن إعدادات وبيانات الإنتاج أصبحت جاهزة. لم تُنشأ حسابات أو بيانات تجريبية في MAS DB المستضافة.

## الخدمات والبيانات المستخدمة

- التطبيق: Next.js 16.3.3 وNode 24.22.1؛ المنفذ المحلي 3100.
- PostgreSQL 17 مع ترحيلات المشروع الستة بعد تهيئة مخططات Auth وStorage الحقيقية.
- Supabase Auth (GoTrue) 2.198.0، وPostgREST 16.5، وStorage API 1.96.0. شُغلت Storage بمحرك Node 26 الخاص بصورتها الرسمية بعد استخراج وقت التشغيل لتجاوز مساحة Docker المحدودة؛ لم تُعدل شيفرتها.
- بوابة محلية تمرر الطلبات للخدمات وتسمح بـCORS لأصل التطبيق المحلي فقط.
- ClamAV 1.5.4 بقواعد `daily 28184` بتاريخ 15 نوفمبر 2026، و`main 63` و`bytecode 339`. حُجب تحديث freshclam بالإنترنت (HTTP 403)، واستُخدمت القواعد الفعلية المرفقة. لم يُستخدم فاحص وهمي يعتمد على اسم الملف أو EICAR وحده.
- واجهة HTTPS محلية حول بروتوكول ClamAV INSTREAM، تتحقق من مفتاح الخدمة وSHA-256. وثق التطبيق شهادة الاختبار المحلية صراحةً؛ لم يُعطل التحقق من TLS.
- مستخدم Auth مؤكد `mas-e2e@example.test` بكلمة مرور عشوائية، تمت تهيئته عبر `mas_bootstrap_owner` باستخدام مفتاح الخدمة المحلي، ثم سجّل الدخول وفعّل TOTP من الواجهة.
- شركة ووحدة وتصنيف وعلامة تجارية وخصوصية وشروط ومنتج وصورة بعبارات واضحة `TEST ONLY`. السياسات والمنتج ليست نصوصًا قانونية أو تجارية معتمدة.
- بيانات الاعتماد وأسرار TOTP والكوكيز والملفات الناتجة محفوظة في `work/` المستثنى من Git؛ لا توجد بيانات اعتماد اختبار ثابتة في المستودع.

| الإدارة | ظهر المرجع في قائمة الطلبات، واحتوى الطلب على snapshot المنتج وSKU والوحدة. حُفظت الملاحظة والإسناد وانتقال الحالة إلى `in_progress`. |
| عرض السعر | حفظ مسودة عبر الواجهة، ثم إصدارها وقفلها؛ نُفذت مهمة PDF فعليًا، وحُفظ الملف في `sales-private` وأصبحت `pdfStatus=ready`. |
| تنزيل PDF | تنزيل رابط Storage الموقّت أعاد 200 وملف `%PDF-` قابلًا للقراءة. ظهر زر التنزيل بعد إعادة تحميل الواجهة. فُحصت الصفحة بصريًا وباستخراج النص. |

## فحوص الشيفرة

- أتاح تعديل إعدادات البيئة الاتصال بـSupabase المحلي عبر HTTP على `localhost` و`127.0.0.1` و`::1` في التطوير فقط. ما زال الإنتاج يتطلب HTTPS، وترفض عناوين HTTP البعيدة وأسماء النطاقات المشابهة وبيانات الاعتماد أو query/hash في الأصل.
- أُضيف اختبار حدود لهذا السلوك. إجمالي الاختبارات: **40 ناجحًا** (10 للواجهة/الكاش و30 للباك إند).
- نجح `typecheck` و`next build` و`git diff --check`.
- ملفات الرحلات التفصيلية وسجلاتها وPDF التجريبي موجودة في مجلد `work/e2e` المحلي المستثنى؛ ليست جزءًا من اختبار `pnpm test:browser` الذي ما زال يشمل اختبارات العقود المعترضة المعلنة في README.

- إعداد SMTP وروابط دعوة/استعادة الحساب وتسليم البريد في الإنتاج لم يُختبر في هذه الرحلة.
